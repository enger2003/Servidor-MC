# Instalación y configuración VPN Zero Tier
Para poder conectarnos de forma remota al servidor, necesitamos tener una VPN. Una VPN es una aplicación que nos permite crear una red simulada de forma que cualquier usuario conectado se considera en la misma red que el servidor. Ya que el servidor está pensado para Linux y los clientes probablemente estén en Windows, necesitamos una VPN disponible para ambos Sistemas Operativos, en nuestro caso, Zero Tier
